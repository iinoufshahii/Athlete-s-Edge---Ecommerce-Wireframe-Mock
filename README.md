# Athlete's Edge — Ecommerce Wireframe Mock

This repository contains wireframe mockups for the **Athlete's Edge** ecommerce experience, covering key customer and internal operations screens.

## Project Scope

The mockups represent UI concepts for:

- Customer-facing shopping flow (homepage, product detail, cart, payment, order tracking)
- Authentication flow (login, sign up)
- Operational/admin views (dashboard, inventory, sales, suppliers, reports, quality control, customer service)
